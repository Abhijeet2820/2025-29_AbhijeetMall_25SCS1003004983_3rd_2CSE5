# CodeSoft Java Programming Internship

This repository contains the projects completed during my Java Programming Virtual Internship at CodeSoft.

## Projects

### 1. ATM Interface
A Java-based ATM simulation that allows users to perform basic banking operations such as checking balance, depositing money, and withdrawing money.

### 2. Student Grade Calculator
A Java program that calculates the total marks, average percentage, and grade based on the marks entered by the user.

### 3. Number Game
A Java-based number guessing game where the user attempts to guess a randomly generated number with the help of hints.
